# LUMA Lab

Somos un proyecto de Uruguay. Hacemos dispositivos para el agro.

El primero es [LumaTrap](https://github.com/lumagro-lab/luma-trap): una trampa con cámara. Saca una foto de lo que cayó adentro y la manda, para no tener que ir a mirar cada trampa.

No abrimos el código de una versión hasta que la siguiente está lista. Cuando termine v1, publicamos v0.X. Cuando termine v2, publicamos v1.

- Sitio: [luma.uy](https://luma.uy)
- Lab: [lab.luma.uy](https://lab.luma.uy)
